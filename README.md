# PersonalBuffs and PersonalHud

Two Ashita v4 addons for HorizonXI by Renavi. They share the same themes, and each one works on its own.

> [!WARNING]
> **Neither addon is currently approved on HorizonXI.** Do not use them on HorizonXI until they show on the approved addon list. Using unapproved addons can get your account banned.

| Addon | Version | Command | Folder |
|---|---|---|---|
| **PersonalBuffs** | 1.2.2 | `/pb` | [`personalbuffs/`](personalbuffs) |
| **PersonalHud** | 1.0 | `/phud` | [`personalhud/`](personalhud) |

### PersonalBuffs

Timers for what you do, in small themed boxes:

- **Buff box:** time left on buffs you cast, on you and on others. Click a row to see each person.
- **Debuff box:** debuffs you put on mobs, one section per mob, your target first. Clears when they wear off or the mob dies.
- **Recast box:** your ability and spell recasts.
- **Party (optional, off by default):** your party members' buffs and debuffs too, marked with their name.
- Hide anything per job, save what you hide as presets, themes, click-through, profiles for other characters.

### PersonalHud

One small box with your name, jobs, HP, MP, TP and XP / LP. Uses the same themes and can match PersonalBuffs' theme.

## Install

1. Download the latest release zip (or **Code → Download ZIP**).
2. Inside the zip, copy the addon folder you want (`personalbuffs` and/or `personalhud`) into `HorizonXI\Game\addons\`.
   You should end up with `addons\personalbuffs\personalbuffs.lua` and/or `addons\personalhud\personalhud.lua`.
3. In game: `/addon load personalbuffs` and/or `/addon load personalhud`

See each addon's own README for details, commands and what it reads.
